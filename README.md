# EGIS 프로토타입

환경융합포털 HTML 프로토타입입니다.  
`file://`이 아니라 **로컬 서버**(Live Server 등)로 열어 주세요.

개발에 필요한 것은 **HTML과 CSS**입니다. JS는 참고용입니다.

바로 보기: [egis/pages/main/index.html](egis/pages/main/index.html)

## 문서 보는 순서

`egis/docs/` 를 **위에서 아래 순서**로 보시면 됩니다.

| 순서 | 문서 | 내용 |
|------|------|------|
| 1 | [structure.md](egis/docs/structure.md) | 파일이 어디에 있는지. 껍데기(`index.html`)와 실제 내용(`fragments/`) |
| 2 | [jsp.md](egis/docs/jsp.md) | HTML 붙이는 법, 화면설계서 순서·클래스 |
| 3 | [css.md](egis/docs/css.md) | CSS·폰트 넣는 법, `@import` |
| 4 | [js.md](egis/docs/js.md) | 화면 동작. `*-app.js`·`fragment-loader.js`는 프로토타입용 |
| 5 | [toast.md](egis/docs/toast.md) | 토스트. 마크업은 `shared/fragments/toast.html` |
