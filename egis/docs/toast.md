# 토스트 문구

화면 위에 짧게 뜨는 안내입니다.  
스타일은 `assets/css/uikit/common/toast.css`에 있습니다. `common.css`를 연결하면 따라옵니다.

## 동작

| 파일 | 하는 일 |
|------|---------|
| `shared/fragments/toast.html` | 마크업. 레이아웃 body 끝에 한 번 넣습니다. |
| `assets/css/uikit/common/toast.css` | 스타일 (`common.css`에 포함) |
| `assets/js/common/toast.js` | `.toast-stack` 안에 항목을 넣고, 보여 주고, 닫습니다. |
| 각 화면 JS | “이 조건이면 이 문구”만 호출합니다. (`Toast.show` / `warning` / `error`) |

HTML은 상자만 있고, 문구 칸은 JS가 그때그때 넣습니다.

```js
Toast.show('다운로드를 시작합니다.');      // 기본
Toast.warning('이미 첨부된 파일입니다.');   // 경고 (노란 아이콘)
Toast.error('파일을 첨부하지 못했습니다.'); // 에러 (빨간 아이콘)
```

문구를 부르는 화면 JS:

| 화면 | JS |
|------|-----|
| 기간 필터 | `assets/js/common/search-filter.js` |
| 주제별 지도 | `assets/js/topical/pin.js`, `render.js`, `detail-page.js` |
| Open API | `assets/js/data-open/open-api/` (`pin.js`, `render.js`, `detail-page.js`, `apply.js`) |
| 문의 등록 | `assets/js/user-support/inquiry-write.js` |
| 마이페이지 | `assets/js/mypage/` (`favorites.js`, `download/list.js`, `authkey/list.js`, `openapi/*.js`) |

## 화면별 문구

이 문구 그대로 쓰시면 됩니다.

### 기간 필터 (검색·주제도·Open API 목록)

| 언제 | 문구 | 종류 |
|------|------|------|
| 종료일이 시작일보다 앞 | 종료일은 시작일 이후 날짜로 선택해 주세요. | 경고 |
| 시작일이 종료일보다 뒤 | 시작일은 종료일 이전 날짜로 선택해 주세요. | 경고 |
| 날짜 형식이 잘못됨 | 날짜 형식을 확인해 주세요. | 경고 |

### 주제별 지도 · Open API 목록

| 언제 | 문구 | 종류 |
|------|------|------|
| 고정 데이터셋 7개째 | 고정 데이터셋은 최대 6개까지 선택할 수 있습니다. | 경고 |
| 관심 데이터 11개째 | 관심 데이터는 최대 10개까지 등록할 수 있습니다. 기존 항목을 삭제한 후 다시 시도해 주세요. | 경고 |

### 상세

| 언제 | 문구 | 종류 |
|------|------|------|
| 공유하기 | 링크가 복사되었습니다. | 기본 |
| Open API 테스트 실행 | 테스트 요청을 실행했습니다. | 기본 |

### Open API 개발계정 신청

| 언제 | 문구 | 종류 |
|------|------|------|
| 필수값 없이 신청 | 필수 입력 항목을 모두 입력해 주세요. | 경고 |
| 신청 완료 | 개발계정 발급 신청이 접수되었습니다. | 기본 |

### 문의 등록

| 언제 | 문구 | 종류 |
|------|------|------|
| 이미지 6개째 | 이미지는 최대 5개까지 첨부할 수 있습니다. | 경고 |
| 허용하지 않는 파일 | 첨부할 수 없는 파일 형식입니다. PNG, JPG, JPEG, GIF, BMP 파일을 첨부해 주세요. | 경고 |
| 같은 파일 다시 첨부 | 이미 첨부된 파일입니다. | 경고 |
| 첨부 합계 10MB 초과 | 첨부파일의 전체 용량이 10MB를 초과했습니다. 일부 파일을 삭제해 주세요. | 경고 |
| 첨부 실패 | 파일을 첨부하지 못했습니다. 잠시 후 다시 시도해 주세요. | 에러 |
| 필수값 없이 등록 | 필수 입력 항목을 모두 입력해 주세요. | 경고 |
| 등록 완료 | 문의가 등록되었습니다. | 기본 |

### 마이페이지

| 언제 | 문구 | 종류 |
|------|------|------|
| 관심 데이터 삭제 | 선택한 관심 데이터가 삭제되었습니다. | 기본 |
| 다운로드 시작 | 다운로드를 시작합니다. | 기본 |
| 인증키 복사 | 인증키가 복사되었습니다. | 기본 |
| 인증키 재발급 | 인증키가 재발급되었습니다. | 기본 |
| Open API 조회, 시작일이 종료일보다 뒤 | 시작일은 종료일보다 이전 날짜로 선택해 주세요. | 경고 |
| Open API 조회, 기간 1년 초과 | 조회 기간은 최대 1년까지 설정할 수 있습니다. | 경고 |
| Open API 조회, 오늘 이후 날짜 | 오늘 이후의 날짜는 선택할 수 없습니다. | 경고 |
| 계정 삭제 | 계정이 삭제되었습니다. | 기본 |
| 기간 연장 | 연장 신청이 완료되었습니다. | 기본 |
| 정보 수정 저장 | 변경사항을 저장했습니다. | 경고 |
| 운영계정 신청 완료 | 운영계정 신청이 완료되었습니다. | 경고 |

운영계정 신청 첨부는 문의 등록과 같고, 파일 1개 10MB·전체 50MB만 다릅니다.

- 파일당 최대 10MB까지 첨부할 수 있습니다. (경고)
- 첨부파일의 전체 용량이 50MB를 초과했습니다. 일부 파일을 삭제해 주세요. (경고)

지도의 `지도를 클릭해 중심점을 지정하세요`는 이 토스트가 아닙니다.
